# SEO Metadata Skill

## Purpose

Use this skill when working on SEO-related content and technical metadata for **Palmiye Nature Hotel & Yacht Club**.

This includes:

```txt
page titles
meta descriptions
Open Graph metadata
Twitter/X card metadata
canonical URLs
localized metadata
image alt text
structured data
sitemap
robots
local SEO copy
hotel SEO keywords
```

The goal is to make the site search-friendly, shareable, accurate, and trustworthy without keyword stuffing or fake hotel claims.

---

## Project Context

Palmiye Nature Hotel & Yacht Club is a small boutique hotel with:

```txt
14 rooms
restaurant
marina / yacht club context
pool with pool bar
rooftop / terrace bar
nature, marina, bay and sunset atmosphere
```

Important rule:

```txt
The hotel has 14 rooms and all rooms are currently considered the same public room type.
Do not create SEO metadata for fake room categories such as Deluxe Room, Suite, King Room, Family Room, Sea View Room or Superior Room unless explicitly confirmed later.
```

an all-inclusive resort

## Canonical and Locale Rules

For multilingual routes, metadata should respect locale.

Preferred Phase 1 routes:

```txt

/en/rooms
```

Each localized page should have:

```txt
canonical URL for itself
alternate URL for other locale when possible
```

Do not point all canonical URLs to the same language page.

---

## Next.js Metadata Rules

Use Next.js metadata APIs where possible.

Good pattern:

```ts
export async function generateMetadata({ params }): Promise<Metadata> {
  const content = await getPageContent(params.locale);

  return {
    title: content.seo.title,
    description: content.seo.description,
    openGraph: {
      title: content.seo.ogTitle,
      description: content.seo.ogDescription,
      images: [content.seo.ogImage],
    },
  };
}
```

Do not hardcode metadata in random components.

Page metadata should come from locale-aware content/config.

Forbidden sitemap entries:

```txt
/admin
/admin/reservations
/admin/settings
/api/*
private dashboard pages
```

---

## Robots Rules

Public promotional pages should be indexable.

Admin and private routes should not be indexed.

Recommended exclusions:

```txt
/admin
/api
/dashboard if private
```

Do not accidentally block the entire site from search engines in production.

---

## Reservation and Admin SEO Rules

Phase 2 may add:

```txt
/reservation
/admin
/admin/reservations
/admin/dashboard
```

Rules:

```txt
Reservation page may be indexable if public and useful.
Admin pages must not be indexable.
Owner dashboard must not be indexable.
API routes must not be indexable.
```

Do not create SEO metadata for private admin pages as if they were public marketing pages.

unless confirmed.

private beach

## Keyword Stuffing Rules

Do not write metadata like this:

```txt
Marmaris hotel, Marmaris hotels, best Marmaris hotel, boutique Marmaris hotel, marina hotel Marmaris, yacht hotel Marmaris
```

Use natural sentences instead.

Good:

```txt
A calm 14-room boutique hotel in Marmaris with marina atmosphere, restaurant, pool bar and rooftop terrace.
```

## Phase 2 Compatibility

Some SEO content may later become editable from the admin panel.

Therefore:

- Keep SEO data structured.
- Store metadata in page content objects or SEO config.
- Avoid scattering metadata strings across unrelated files.
- Use stable page slugs.
- Keep locale-specific SEO fields easy to migrate to a database.

Potential backend model later:

```txt
site_pages
page_seo
localized_content
gallery_images
hotel_settings
```
